# Frameshelf

Frameshelf is a responsive website-inspiration hub for browsing, saving, and sharing design references. Each entry includes a visual preview, category, tech stack, color palette, and a link to the live site.

## Features

- Search websites by title, category, tech stack, description, or author.
- Filter by category and technology; sort by trending, newest, or name.
- Save favorites, like designs, and copy palette colors.
- Open responsive previews and share website references.
- Add website submissions with a URL, description, stack, and custom palette.
- Switch between light and dark themes.
- Browse trending designs, categories, and recent additions.

## Run locally

No build step or package installation is required. Open `Frameshelf.html` in a modern browser. An internet connection is needed to load the page's CDN-hosted React, Tailwind CSS, Babel, and Google Fonts.

The app stores its demo content, preferences, and session in browser `localStorage`, so they stay in that browser on the same device.

## Demo account

Authentication is simulated in the browser; there is no backend or real account security. Use any valid email and a password of at least six characters to sign in. To view the demo admin dashboard, use an email beginning with `admin`.
